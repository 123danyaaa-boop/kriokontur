# Инструкция для Claude Code

Проект: цифровой контур кейса «Топливный космоконтур 2035». Перед любой правкой прочитай
`docs/MATH_MODEL.md` и `docs/ARCHITECTURE.md`.

## Жёсткие правила

1. `data/*.csv` это данные организатора. Кодом не правим, значения не подгоняем.
   Если нужно другое значение, это отдельный сценарий в `configs/scenarios` со статусом TEAM_*.
2. Любое число, которого нет в `data/`, это допущение. Оно живёт в `plan.assumptions`
   с именем, значением, единицей и обоснованием и попадает в выгрузку.
3. Формулы кейса лежат только в `src/kriokontur/rules.py`. Не дублируй их в движке, в API
   и тем более во фронтенде.
4. Каждое новое правило проверяется тестом. `python -m pytest tests -q` должен быть зелёным
   до и после правки.
5. Нарушение это код, период, факт, лимит, превышение и человеческое сообщение.
   План не чиним автоматически.
6. Надёжность не множитель поставки. Доли 55% и 75% в стрессе повторно не умножаются.
7. Выручки и стоимости срыва миссии в модели нет.

## Чего не делать

- Не переносить расчёт во фронтенд.
- Не хранить результаты в коде или в статических таблицах.
- Не смешивать обязательный стресс с высоким спросом в одном прогоне.
