# Как запустить. Пошагово, ничего не пропуская

Нужен только Python или Docker.

## Docker

```bash
docker compose up -d
```

Приложение запуститься и будет доступно на http://localhost:8000.

## Python

### Шаг 0. Проверить, что Python есть

Откройте терминал и наберите:

```
python --version
```

Если пишет `Python 3.10` или больше, всё в порядке. Если команда не найдена, попробуйте `python3 --version`.
Если и так не найдено, поставьте Python с python.org и при установке на Windows поставьте
галочку «Add Python to PATH».

Дальше везде: если у вас `python3`, пишите `python3` вместо `python`.

### Шаг 1. Распаковать проект и зайти в папку

```
cd путь/к/папке/kriokontur
```

Проверьте, что вы в нужной папке: команда `dir` на Windows или `ls` на macOS и Linux должна показать
файлы `run.py`, `requirements.txt` и папки `src`, `data`, `web`.

### Шаг 2. Запустить одной командой

```
python run.py
```

Совсем без терминала: двойной клик по `start.command` на macOS, по `start.bat` на Windows или `start.sh` на Linux.

Скрипт сам: проверит версию Python, доустановит недостающие библиотеки, прогонит тесты расчёта,
посчитает контрольный план и поднимет сервер. Вы увидите примерно такое:

```
[ШАГ] проверяю Python
  ок, Python 3.13.3

[ШАГ] проверяю библиотеки
  всё на месте

[ШАГ] прогоняю тесты расчёта
........................................................................ [100%]
158 passed in 4.48s

[ШАГ] считаю контрольный план в двух сценариях
  BASE               приведённые расходы 8919 млн, обслуживание 100.00%, жёстких нарушений 0
  MANDATORY_STRESS   приведённые расходы 10275 млн, обслуживание 100.00%, жёстких нарушений 0

[ШАГ] поднимаю сервер

  ┌──────────────────────────────────────────────────┐
  │  Интерфейс оператора:  http://0.0.0.0:8000       │
  │  Документация API:     http://0.0.0.0:8000/docs  │
  │  Остановить сервер:    Ctrl+C                    │
  └──────────────────────────────────────────────────┘
```

Если порт 8000 занят, скрипт сам возьмёт следующий свободный из диапазона 8000–8010
и напишет об этом строкой «порт 8000 занят, беру свободный 8001».

### Шаг 3. Открыть в браузере

Браузер откроется сам, как только сервер будет готов. Если этого не произошло,
перейдите на адрес вручную. Это рабочее место оператора: слева решения,
в центре план и проверки, справа итог. В правом верхнем углу зелёная точка и надпись
«живой расчёт на бэкенде» означают, что интерфейс считает через Python, а не показывает картинку.

Чтобы остановить сервер, вернитесь в терминал и нажмите Ctrl+C.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `python: command not found` | попробуйте `python3`, иначе поставьте Python с python.org |
| `нужен Python 3.10 или новее` | обновите Python |
| страница не открывается | посмотрите адрес в рамке: при занятом порте он не 8000, а следующий свободный |
| браузер не открылся сам | откройте адрес из рамки руками, либо запускайте с ключом `--no-browser` и открывайте сами |
| тесты не прошли | сервер не поднимется специально: сначала чиним расчёт, покажите вывод команде |
| долго ставит библиотеки | это один раз, дальше запускается за секунды |
| в браузере жёлтая точка и «демо-снимок» | бэкенд не отвечает: проверьте, что терминал с `python run.py` не закрыт |

## Полезные команды

```
python run.py --check             только проверить окружение и посчитать план, без сервера
python run.py --skip-tests        запустить сервер, не прогоняя тесты
python run.py --port 8080         начать подбор порта с другого номера
python run.py --no-browser        не открывать браузер
python -m pytest tests -q         только тесты
```

Расчёты без интерфейса, из терминала (перед командой нужен `PYTHONPATH=src`, на Windows
в PowerShell это `$env:PYTHONPATH="src"` отдельной строкой):

```
PYTHONPATH=src python scripts/run_all_scenarios.py --plan configs/plans/final-candidate.json
PYTHONPATH=src python scripts/sensitivity_report.py
PYTHONPATH=src python scripts/risk_report.py
PYTHONPATH=src python scripts/horizon_report.py --method increment
PYTHONPATH=src python scripts/extensibility_demo.py
PYTHONPATH=src python -m kriokontur.cli compare --plan configs/plans/final-candidate.json
PYTHONPATH=src python -m kriokontur.cli export --plan configs/plans/final-candidate.json --scenario BASE --out results
```

## Демо без установки

Файл `kriokontur-demo.html` в корне папки открывается двойным кликом в любом браузере
и работает без Python: внутри снимок расчёта. Редактировать план в нём нельзя — все элементы,
которым нужен пересчёт, выключены, вверху висит плашка с причиной, а на каждой выключенной
кнопке та же причина всплывающей подсказкой. Зато видно все экраны, сценарии, проверки
и расчёт на перспективу.

Если при открытом демо запустить `python run.py`, страница найдёт бэкенд сама за несколько
секунд, уберёт плашку и включит все элементы — перезагружать её не нужно.

Пересобрать снимок после изменений интерфейса или расчёта:

```
PYTHONPATH=src python scripts/build_demo.py
```
